# Banking System

This is a simple console-based banking system written in Python. It supports checking and savings accounts, deposits, withdrawals, transfers, and user authentication.

## Features

- User authentication (email and password validation)
- Checking and savings accounts
- Deposits, withdrawals, and transfers
- Input validation and error handling

## Prerequisites

- Python 3.8 or higher

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/BankingSystem.git
   ```
2. Navigate to the project directory:
   ```
   cd BankingSystem/Develop
   ```
3. Ensure the `Assets` folder is alongside the `Develop` folder:
   ```
   BankingSystem/
   ├── Develop/
   │   └── main.py, BankingClasses/, BankingFunctions/
   └── Assets/
       └── python-terminal-*.png
   ```

## Usage

Run the application:
```
python main.py
```

Follow the prompts to log in and manage your accounts.
